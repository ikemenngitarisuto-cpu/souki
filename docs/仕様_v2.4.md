# 想起 v2.4 / v2.5 仕様（2026-10-31 確定）

v2.3.0 を使ってみて出た要望（Qwen-Image 2.1 の参照画像合成、着替工房のワークフローで差し替えが効かない、
Chrome の新しいタブで開く）と、残っていた第 2 弾（A・B・D）をまとめたもの。2 回に分けて作る。

---

## 第 1 弾（v2.4.0）

### 1. 窓に分けたワークフロー（着替工房など）

**原因（v2.3.0 で確認）** … プロンプトが「窓 → つなぐ → 仕上げ」や専用ノード（KigaeKoboPrompt）を通ってから
CLIP Text Encode に入るワークフローを、想起がたどれなかった。そのため

- 差し替えは、最初に見つかった「文字入りの CLIP Text Encode」＝**ネガティブ**を書き換えていた
  （差し替え先の子の特徴がネガティブに足され、逆向きに効いていた）
- 台帳にも、ネガティブが「ポジティブ」として入っていた（タグ一覧に worst quality などが混ざる）
- 専用ノード版は保存名が線でつながっているので、保存名のひな形も効いていなかった

**仕様**

- **プロンプトのたどり方を直す**
  - サンプラの positive からさかのぼり、文字の窓・つなぐ（StringConcatenate など）・置き換え（RegexReplace など）を全部たどる
  - 区切り文字・正規表現・置き換え先などの欄は読まない
  - 出口が複数あるノードは、つながっている出口で読み分ける（例：TextEncodeQwenImage21 の 0 番＝プロンプト、1 番＝ネガティブ）
  - 切り替えノード（ComfySwitchNode など）は、そのとき有効な側だけたどる
  - **ネガティブ側の欄には決して触らない**。たどれないときはネガティブを選ばず「書き換える欄が見つかりません」と知らせる
- **窓ごとに入れ替える**
  - 窓の名前（ノードのタイトル。API 形式の `_meta.title`）を見て、キャラの語はキャラの窓へ、服は服の窓へ
  - 服の窓は中身ごと新しい服にする
  - 名前で決まらないときは、元の語があった窓に入れる。入れる語が全部の窓に重複して入らないようにする
- **着替工房の専用ノード（KigaeKoboPrompt）**
  - ファイル名の番号（`着替工房/01_メイド_00001_.png` の 01）から、その絵の服の行を特定する
  - 投入は「番号の行だけ」＋その番号で、その絵の服の行だけ出し直す
  - 服を替えるときは、その行を新しい服に書き換える（行頭に【服の名前】）。ほかの行はそのまま
- **保存名**
  - 線でつながった保存名（filename_prefix がほかのノードから来ている）も、ひな形の名前に書き直す
    （API 形式では線を文字に置き換え、画面用ワークフローでは線を外して値を入れる）
  - 保存の欄が 2 つ以上あるとき（1 枚ずつ＋一覧など）は、2 つ目以降に元の名前の最後の部分を付け足す（例：`…illuルル_一覧`）
  - ひな形に `{服}` を書けるようにする（服の名前が入る。最初の形には入れない）
- **画面用ワークフロー**
  - 新しい ComfyUI の「名前つきの値」（`widgets_values_named`）も、`widgets_values` と一緒に直す
  - サブグラフの中の値（API 形式で `459:458` のような番号のノード）は、外側のサブグラフのノードの値で直す（seed など）
- **台帳の読み直し**
  - 起動したとき裏で 1 回、保存してあるワークフロー（prompt_json）からポジティブ・ネガティブ・タグを読み直す
  - 画像ファイルは読まない（1〜2 分）
  - 直った絵は、キャラ帳の特徴語（c_analysis.words）も読み直す。「2 人以上」と分かった絵は 1 人扱いをやめる（逆は変えない）

### 2. Qwen-Image 2.1（参照画像で何人も入れる絵）

- **台帳の読み取り**
  - TextEncodeQwenImage21（プロンプトとネガティブが 1 つのノード、参照画像は image_1, image_2 …）とサブグラフ、プロンプト強化（Prompt Enhancer）の切り替えに対応
  - 文章のプロンプトはタグ一覧に入れない（検索欄では探せる）
- **参照画像を覚える**
  - どの枠（image_1 …）にどの絵を入れたか（Load Image のファイル名）を覚える
  - ComfyUI の input にある絵の控えを想起に取っておく（data/refs、中身が同じものは 1 つ）
  - 台帳の絵と同じ絵なら「元の絵」としてつなぐ
  - 絵を開くと、参照画像が並ぶ
- **投入の確認と復元**
  - 参照画像が ComfyUI の input から消えていたら、ランプで知らせる（今はモデルしか確かめていない）
  - 投入するとき、控えから ComfyUI に戻す（/upload/image）

### 3. 何人か写っている絵の保存名

- 投入前に聞くのをやめ、写っている子を**左から順に「と」でつなぐ**（例：`…illuルルとピナとナナ`）
- 差し替えたときは、その子の名前だけ入れ替える
- キャラが 1 人も分からないときだけ聞く

### 4. 専用の窓（タブではない窓で開く）

- **Edge の専用窓**（タブもアドレス欄もない窓。台割工房と同じ）で開く。想起専用の設定フォルダを使う
- 窓の大きさと位置を覚える
- **黒い窓は出さない**（pythonw で動かす）
  - 専用の窓を閉じたら想起も終わる。解析などの途中なら、終わるまで裏で続けてから終わる
  - 動いているときに起動.bat を開いたら、窓だけ開く
  - 記録は data フォルダにファイルで残す。起動できないときはメッセージの窓で知らせる
  - 最初の準備（setup）のときだけは、今までどおり黒い窓が出る
- 台帳⇄キャラ帳は同じ窓の中で切り替え。今は新しいタブで開いていた「台帳で開く」「台帳でこの子の絵を見る」も同じ窓で
- ComfyUI の画面がどこにも開いていないときに開く場合も、Edge の専用窓で開く
- Edge が無いときは、今までどおりいつものブラウザで開く

## 第 2 弾（v2.5.0）

### 参照画像の差し替え

- 枠ごとに「このまま／ほかの絵に替える」
- キャラ帳で枠の子を見分け、差し替え先の子の絵、その服を着た絵を台帳から候補に出す（服の参照画像の枠なら、服の絵）
- 文章のプロンプトは語の入れ替えをしない

### 語で描いた 2 人以上の絵

- 差し替える子を選び、その子の特徴の語だけ入れ替える（今は全員分の特徴が入れ替わる）

### A. LoRA も差し替え

- キャラの画面で、その子の LoRA・強さ・トリガー語を持たせる（台帳から自動で推し量り、手で直せる）
- 差し替えるとき、LoRA とトリガー語も入れ替える
- 元の絵に LoRA ノードがなければ、モデルのすぐ後ろに足す（足せない構成のときは知らせる）
- 標準の LoRA ノードと rgthree の Power Lora Loader に対応

### B. まとめて差し替え

- 差し替え先を何人か選んで、1 人ずつ投入（参照画像の枠をいくつか同時に替えるのもここ）
- 「全員同じ seed」で、同じ構図のまま見比べられる
- 服装は「全員元の絵のまま／それぞれのいつもの服／全員同じ登録服」

### D. 差し替えの記録

- 投入するとき PNG に「どの絵から・誰に・どの服で」を書き込む（extra_pnginfo の souki）
- できた絵から元の絵へ飛べ、元の絵からは「この絵から作った絵」を一覧できる
- 参照画像の「元の絵」とも同じしくみでつなぐ
