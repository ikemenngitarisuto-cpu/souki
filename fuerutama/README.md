# ふえる玉 v2.0 — 玉が分かれて増えていくのを、ずっと眺めるソフト

円の中で仕掛けが動き、刃に挟まれた玉が **2〜4 個に分かれて** 増えていきます。
円がいっぱいになっても、玉どうし重なりながら **決めた数まで増えつづけ**、最後は **円が割れて玉が飛び散る** か、
**全部が金色** になって、また 1 個から始まります。2 回に 1 回くらい、玉を **減らすもの** が出てきてケンカします。
仕掛け・刃の数と形・色・玉の大きさ・分かれる数は毎回かわるので、放っておけばいつまでも続きます。

---

## v2.0 で変わったこと（参考の動画に寄せて、一から作り直しました）

- **動きの芯を作り直しました。** どの仕掛けも同じ流れです。
  1. 刃が **寄ってきて**、玉を囲いこむ
  2. **締める** … 囲まれた玉が白く光り、挟まれた玉は白いかたまりになる
  3. 閉じきった瞬間に、かたまりの玉が **いっせいに分かれる**（数字もここで上がる）
  4. 生まれた玉は、刃のすき間（出口）から **かたまりで飛び出す**。出たては小さく、ふくらみながら広がる
- **玉が動画と同じ見た目になりました。** 大きめで、黒いふちどりと白い光の点つき。新しく生まれた玉ほど上に描くので、重なっても新しい色が見えます。
  玉の大きさに **特大**（動画と同じくらい）が増えました。
- **仕掛けを動画どおりの動きにしました。**
  - 寄せ刃（3〜8 枚）… 線路をすべって寄る → 多角形に閉じる → ゆっくり締める → 開く。生まれた玉は角から飛び出す
  - 8 の字 … 2 組の弧が逆向きに **止まらず回り続ける**（前は開いて閉じての往復でした）
  - はさみ箱 … 棒がすべって入り、先の羽根が **折れて** 箱になり、横に締まる
- **減るものが「行ったり来たりの勝負」になりました**（くわしくは下の表）。
  食べる玉は育ち、穴は開いたり閉じたりし、寿命は目に見え、消し刃の赤は広がって引いていきます。どれも、いつかは引き下がります。
- **混んできたときの計算を作り直しました。** 玉の「当たりの大きさ」を数に合わせて縮めるので、見た目は重なり、中身はなめらかに流れます。
  10 万個のときの計算は、v1.1 より 3 割ほど軽くなりました。
- **音** … はじける音は、刃が閉じるたびに音程が上がっていきます（15 回でひとまわり）。玉がたくさんのときは、粒の音が「ザーッ」という 1 本の音になります。割れる前には、上がっていく音が鳴ります。
- **設定** … プリセット（おまかせ／動画ふう／大洪水／ケンカ／ゆったり）、気に入った組み合わせの **固定（📌）**、**記録**（見た回数・いちばん多かった玉・減るものとの勝ち負け）、進み具合の輪。

**v1.x からは上書きするだけです。** 前の設定はそのまま引き継ぎます。

## 動かし方

1. zip を好きな場所に展開します（中のファイルは同じフォルダに置いたままにしてください）。
2. **`起動.bat`** をダブルクリックします。Edge の専用の窓で開き、すぐ音も出ます。
   - Edge が見つからないときは、いつものブラウザで開きます。
   - `fuerutama.html` を直接ダブルクリックしても動きます（このときは、画面を 1 回クリックすると音が出ます）。
3. **F キー**（または画面をダブルクリック）で全画面になります。もう一度押すと戻ります。

インターネットにはつなぎません。音もその場で作っているので、ファイルはこれだけです。

## 1 回の流れ

1. 円の中に玉が 1 個ぽんと出ます。名札に、その回の組み合わせ（仕掛け・玉の大きさ・分かれる数・減るもの）が出ます。
2. 刃が閉じるたびに、挟まれた玉が分かれます（1 → 3 → 9 → …）。上の数字が玉の数です。閉じるたびに、生まれる玉の色が変わります。
   - 玉が少ないうちは、仕掛けが玉を待ってから閉じます（なかなか増えない回をなくすため）。
   - 生まれた玉は、次に刃が閉じる 1 回は守られます（挟まれても、刃の下をすり抜けます）。
3. 玉が 30〜50 個になると、その回の「減るもの」が出てきます（出てこない回もあります）。ケンカの様子は、名札の下に赤い字で出ます。
4. 円がいっぱいになっても、玉どうし重なりながら増えつづけます。円の外側の輪が、決めた数までの進み具合です。
5. 決めた数に届くと、円のふちに白い粒が並んでふるえ、割れて玉が外へ飛び散ります。そして次の回へ。
   - ときどき、決めた数ちょうどで全部が金色になって終わります（決めた数が 1 万個のときは、かならず金色）。
   - 減るものに全部消されたら「〇〇の勝ち（全滅）」と出て、次の回へ進みます。

## 仕掛け（3 種）

| 仕掛け | 動き | 生まれた玉の出口 | 選べるもの |
|---|---|---|---|
| 寄せ刃（2 枚＝プレス） | 待つ → 閉じる → すぐ開く | すき間に沿って左右へ | 形 まっすぐ・弧・ギザギザ・くの字 |
| 寄せ刃（3〜8 枚） | 線路をすべって寄る → 多角形に閉じる → ゆっくり締める → 開く | 刃と刃の角 | 刃の数 3・4・5・6・8 枚、形は上と同じ |
| 8 の字 | 2 組の弧が、軸のまわりを逆向きに回り続ける。弧がそろうと輪になり、行き違って細り、つぶれる | 輪の先の外 | 輪の数 2〜5 個、刃の形 弧・まっすぐ |
| はさみ箱 | 棒 2 本がすべって入り、先の羽根が折れて箱になり、横に締まる。逆の順で戻る | 蝶番の 2 つの角 | — |

- 寄せ刃（3 枚以上）は、玉が増えてくると、刃が浮いたまま（うすく見えます）寄ってきて、真ん中の近くで降りて玉をつかまえます。
  円の外から全部かき集めると、増え方が速すぎて、円の中がいつも空っぽに見えるためです。
- 特大の玉のとき、8 の字の輪は 4 つまでです（5 つだと輪が小さくて、玉が入れません）。

## 減るもの（4 つ）

| 減るもの | 出てくる数 | 動き | 終わり方（玉の勝ち） |
|---|---|---|---|
| 食べる玉 | 30 個 | むらさきの丸いやつが、玉を吸いこんで食べる。**食べるほど大きくなる**。小さいうちは、囲いこまれてもひょいとよける。おなかいっぱいになると、のろくなって真ん中へ寄っていき、**刃に挟まれてはじけ、食べた玉を吐き出す** | 決まった数をやっつける（弱い 2・ふつう 3・強い 5 匹。ふつうは 2 匹、強いは 3 匹が同時に出る） |
| 穴 | 40 個 | 円のふちに **ひびが入って知らせ**、開いて、数秒で閉じる。開いている間は、穴へ向かって玉が吸い出される。2 回目からは玉が増えてから開き、**混んでいるほど勢いよく噴き出す**（開いている間は、少し引いて映します） | 決まった回数だけ開いて、ぜんぶふさがる（弱い 2・ふつう 3・強い 4 回。強いは 2 つ同時） |
| 寿命 | 30 個 | 年をとった玉は **色あせて**、しぼんで消える。同じときに生まれた玉がまとめて消えるので、数が波うつ。寿命はだんだん長くなる | 決まった時間がたって、寿命がなくなる（弱い 16・ふつう 22・強い 28 秒） |
| 消し刃 | 50 個 | 刃が 1 枚ずつ **赤くなって広がり**、しばらくして 1 枚ずつ引いていく。赤い刃どうしに挟まれた玉は、分かれずに消える（赤い刃とふつうの刃なら半々） | 赤がぜんぶ引く |

- 玉が 0 個になれば、減るものの勝ち（全滅）です。決めた数に届けば「増えるほうの勝ち！」。
- 強さ（設定）の目安: **弱い** は、まず玉が勝ちます。**ふつう** は、たまに負けます（寿命と消し刃で 10 回に 1 回くらい。食べる玉と穴には、まず負けません）。**強い** は 3 回に 1 回くらい負けます。
- 勝ち負けは、設定の欄の「記録」に残ります。

## 操作

マウスを動かす（スマホは画面をさわる）と、下に操作の帯が出ます。しばらくさわらなければ、帯もマウスの矢印も消えます。

| ボタン | キー | すること |
|---|---|---|
| ⏸ ／ ▶ | スペース | 止める・動かす |
| ⏭ | N（または →） | 次の回へ |
| 仕掛けの欄 | 1〜3 ／ 0 | 仕掛けを選ぶ（1 寄せ刃・2 8 の字・3 はさみ箱）／ 0 でおまかせ |
| 📌 | P | 今の組み合わせ（仕掛け・刃・玉の大きさ・分かれる数・減るもの）を固定する・外す |
| 🔊 | M | 音を消す・出す |
| 音量のつまみ | ↑ ↓ | 音量 |
| ⚙ | | 設定（下の表） |
| ⛶ | F（または画面をダブルクリック） | 全画面 |
| | C | 玉の数を出す・消す |

### 設定（⚙）

いちばん上の **プリセット** で、まとめて切りかえられます。

| プリセット | 中身 |
|---|---|
| おまかせ | 全部おまかせ（最初の状態） |
| 動画ふう | 特大の玉・4 つに分かれる・守らない・減るものなし（参考の動画に近い見た目） |
| 大洪水 | 極小の玉・4 つに分かれる・10 万個まで・はやい・強く飛び出す・計算は軽く |
| ケンカ | 減るものを、かならず出す |
| ゆったり | 大の玉・3 つに分かれる・ゆっくり・円の 2 倍まで・減るものなし |

| 見出し | 項目 | 中身 |
|---|---|---|
| 基本 | 玉の大きさ | おまかせ／特大／大／中／小／極小 |
| | 分かれる数 | おまかせ／2 つ／3 つ／4 つ（おまかせでは、小・極小の玉のときは 3 つか 4 つ） |
| | 速さ | ふつう／ゆっくり／はやい／とてもはやい |
| 増え方 | どこまで増やす | おまかせ（円の 3 倍）／円いっぱいまで／円の 2 倍／円の 5 倍／1 万個／3 万個／10 万個 |
| | 混んできたら | 重なる／少し小さくなる／小さくなる |
| | 生まれた玉を守る | 次の 1 回／次の 2 回／守らない（守らないと、刃の間に残った玉がどんどん増えます） |
| | 飛び出す勢い | ふつう／強く／弱く |
| 減るもの | 減らすもの | おまかせ（2 回に 1 回くらい）／かならず出す／なし／食べる玉／穴／寿命／消し刃 |
| | 強さ | ふつう／弱い／強い |
| 寄せ刃 | 刃の数 | おまかせ／2 枚（プレス）／3 枚／4 枚（十字）／5 枚／6 枚／8 枚 |
| | 刃の形 | おまかせ／まっすぐ／弧／ギザギザ／くの字 |
| 8 の字 | 輪の数 | おまかせ／2〜5 つ |
| | 刃の形 | おまかせ／弧／まっすぐ |
| 見え方 | 進み具合の輪 | 出す／出さない |
| | 画面の揺れ | あり／なし |
| | 計算の細かさ | ふつう／軽く（玉がとても多いとき）／なめらか |
| 表示と音 | 音量・玉の数を出す | 音量は、画面のせまいとき（スマホなど）ここに出ます |
| 記録 | | 見た回数・いちばん多かった玉・減るものとの勝ち負け |

- 「速さ」「混んできたら」「守る」「飛び出す勢い」「進み具合の輪」「画面の揺れ」「計算の細かさ」は、変えるとその場から効きます。ほかは、変えるとすぐ次の回になります。
- 📌 で固定している間は、毎回その組み合わせになります。設定やプリセットを変えると、固定は外れます。
- 設定と記録は、この PC のブラウザが覚えています（次に開いたときも同じ）。

## 困ったとき

- **音が出ない** … 画面を 1 回クリックしてください（ブラウザは、さわるまで音を出さないきまりです）。🔊 が消音になっていないかも見てください。
- **動きがかくかくする** … 玉が多すぎます。設定の「どこまで増やす」を小さく、「計算の細かさ」を「軽く」に、「玉の大きさ」を「大」か「特大」にしてください。
  重いときは、計算の細かさを自動で下げます。
- **玉に光のにじみが出ない・絵が少しちがう** … グラフィックスの加速（GPU）が使えない PC では、玉を 1 個ずつ貼る描き方に自動で切りかわります（そのほうが何倍も速いため）。動きは同じです。
- **1 回が長い** … 「分かれる数」が 2 つで、玉が小さい回は長くなります（極小で 2 分近く）。分かれる数を 3 つか 4 つにするか、「どこまで増やす」を小さくしてください。
- **窓の大きさを最初にもどしたい** … ふえる玉を閉じてから、`data` フォルダを消してください（専用の窓の設定がここに入っています）。
