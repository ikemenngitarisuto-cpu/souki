# ふえる玉 v1.0 — 玉が分かれて増えていくのを、ずっと眺めるソフト

円の中で仕掛けが動き、挟まれた玉が **2〜4 個に分かれて** 増えていきます。
円がいっぱいになると色の陣取りが始まり、最後は **円が割れて玉が飛び散る** か、**1 万個がそろって金色** になって、
また 1 個から始まります。仕掛け・色・玉の大きさ・分かれる数は毎回かわるので、放っておけばいつまでも続きます。

---

## 動かし方

1. zip を好きな場所に展開します（中のファイルは同じフォルダに置いたままにしてください）。
2. **`起動.bat`** をダブルクリックします。Edge の専用の窓で開き、すぐ音も出ます。
   - Edge が見つからないときは、いつものブラウザで開きます。
   - `fuerutama.html` を直接ダブルクリックしても動きます（このときは、画面を 1 回クリックすると音が出ます）。
3. **F キー**（または画面をダブルクリック）で全画面になります。もう一度押すと戻ります。

インターネットにはつなぎません。音もその場で作っているので、ファイルはこれだけです。

---

## 1 回の流れ

1. 円の中に玉が 1 個ぽんと出ます。
2. 仕掛けが閉じるたびに、挟まれた玉がつぶれて分かれます（1 → 3 → 9 → …）。上の数字が玉の数です。
   閉じるたびに、生まれる玉の色が変わります。
3. 円がいっぱいになると、つぶれた玉のまわりがその色に染まり、色の陣取りになります。
4. 円のふちに白い粒が並んでふるえたら、もうすぐ割れます。割れると玉が外へ飛び散り、次の回へ。
   - 玉が「極小」の回は、ちょうど **10,000 個** で全部が金色になって終わります（ほかの回でもときどき金色になります）。

## 仕掛け（4 種）

| 仕掛け | 動き |
|---|---|
| プレス | 上と下の板が寄ってきて、間の玉をつぶす |
| 十字 | 斜めの 4 本の棒が寄って四角になり、真ん中をつぶす |
| 8 の字 | 2 組の弧がハサミのように閉じて、輪の中をつぶす（全体がゆっくり回る） |
| はさみ箱 | 左右から「[」と「]」が入ってきて箱になり、横から挟んでつぶす |

ふだんは「おまかせ」で、毎回ちがう仕掛けになります。

## 操作

マウスを動かす（スマホは画面をさわる）と、下に操作の帯が出ます。しばらくさわらなければ、帯もマウスの矢印も消えます。

| ボタン | キー | すること |
|---|---|---|
| ⏸ ／ ▶ | スペース | 止める・動かす |
| ⏭ | N（または →） | 次の回へ |
| 仕掛けの欄 | 1〜4 ／ 0 | 仕掛けを選ぶ（1 プレス・2 十字・3 8 の字・4 はさみ箱）／ 0 でおまかせ |
| 🔊 | M | 音を消す・出す |
| 音量のつまみ | ↑ ↓ | 音量 |
| ⚙ | | 設定（下の表） |
| ⛶ | F（または画面をダブルクリック） | 全画面 |

### 設定（⚙）

| 項目 | 中身 |
|---|---|
| 玉の大きさ | おまかせ／大／中／小／極小（極小は 1 万個まで増えて金色で終わる） |
| 分かれる数 | おまかせ／2 つ／3 つ／4 つ |
| 速さ | ゆっくり／ふつう／はやい／とてもはやい |
| 玉の数を出す | 上の数字を出すかどうか（C キーでも切りかえ） |
| 音量 | 画面のせまいとき（スマホなど）は、ここに出ます |

設定はこの PC のブラウザが覚えています（次に開いたときも同じ）。

## 困ったとき

- **音が出ない** … 画面を 1 回クリックしてください（ブラウザは、さわるまで音を出さないきまりです）。🔊 が消音になっていないかも見てください。
- **動きがかくかくする** … 設定の「玉の大きさ」を「大」か「中」にしてください（玉の数が少なくなります）。
- **窓の大きさを最初にもどしたい** … ふえる玉を閉じてから、`data` フォルダを消してください（専用の窓の設定がここに入っています）。
