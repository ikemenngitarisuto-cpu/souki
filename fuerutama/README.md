# ふえる玉 v1.1 — 玉が分かれて増えていくのを、ずっと眺めるソフト

円の中で仕掛けが動き、刃に挟まれた玉が **2〜4 個に分かれて** 増えていきます。
円がいっぱいになっても、玉どうし重なりながら **決めた数まで増えつづけ**、最後は **円が割れて玉が飛び散る** か、
**全部が金色** になって、また 1 個から始まります。ときどき、玉を **減らすもの** が出てきてケンカします。
仕掛け・刃の数と形・色・玉の大きさ・分かれる数は毎回かわるので、放っておけばいつまでも続きます。

---

## v1.1 で変わったこと

- **増え方が理論どおりになりました。** 挟まれた玉は必ず決まった数に分かれ、円がいっぱいになっても止まりません。
  玉どうしが重なってゴチャゴチャになりながら、設定の「どこまで増やす」（ふだんは円の 3 倍）まで増えます。最大 10 万個まで選べます。
- **刃の数と形を選べるようになりました。**
  - プレスと十字は **寄せ刃** にまとまりました。刃 2〜8 枚（2 枚が前のプレス、4 枚が前の十字）、形は まっすぐ・弧・ギザギザ・くの字。
  - **8 の字** は輪が 2〜5 個、刃の形は 弧・まっすぐ（ひし形の輪）。
- **減るものとケンカします**（30 個まで増えたところで出てきます）。
  - **食べる玉** … 黒い玉がうろうろして、触れた玉を吸いこんで食べる。食べるほど大きくなるが、おなかがいっぱいだと食べるのが遅くなる
  - **穴** … 円のふちにすき間が開いて、玉がこぼれ出る。すき間はゆっくり回る
  - **寿命** … 時間がたった玉から、しぼんで消える
  - **消し刃** … 赤くなった刃に挟まれた玉は、分かれずに消える
  - 増えるほうが決めた数に届けば「増えるほうの勝ち！」。減るものに押さえこまれたら「〇〇の勝ち」（玉がなくなれば全滅）で、次の回へ進みます。
- **刃の間に漂った玉が何度も増えないように** しました。生まれた玉は刃の外へはじき出され、次に刃が閉じる 1 回はつぶれません。
- 込み入ったところは、⚙ の設定で変えられます（下の表）。

**v1.0 からは上書きするだけです。** 前に選んだ「プレス」「十字」は、寄せ刃 2 枚・4 枚として引き継ぎます。

## 動かし方

1. zip を好きな場所に展開します（中のファイルは同じフォルダに置いたままにしてください）。
2. **`起動.bat`** をダブルクリックします。Edge の専用の窓で開き、すぐ音も出ます。
   - Edge が見つからないときは、いつものブラウザで開きます。
   - `fuerutama.html` を直接ダブルクリックしても動きます（このときは、画面を 1 回クリックすると音が出ます）。
3. **F キー**（または画面をダブルクリック）で全画面になります。もう一度押すと戻ります。

インターネットにはつなぎません。音もその場で作っているので、ファイルはこれだけです。

## 1 回の流れ

1. 円の中に玉が 1 個ぽんと出ます。
2. 刃が閉じるたびに、挟まれた玉がつぶれて分かれます（1 → 3 → 9 → …）。上の数字が玉の数です。
   閉じるたびに、生まれる玉の色が変わります。生まれた玉は外へはじき出されます。
3. 30 個まで増えると、その回の「減るもの」が出てきます（出てこない回もあります）。
4. 円がいっぱいになっても、玉どうし重なりながら増えつづけます。
5. 決めた数に届くと、円のふちに白い粒が並んでふるえ、割れて玉が外へ飛び散ります。そして次の回へ。
   - ときどき、決めた数ちょうどで全部が金色になって終わります（玉が「極小」の回は半分くらい）。

## 仕掛け（3 種）

| 仕掛け | 動き | 選べるもの |
|---|---|---|
| 寄せ刃 | まわりから刃が真ん中へ寄ってきて、間の玉をつぶす（2 枚はプレス、4 枚は十字） | 刃の数 2〜8 枚、形 まっすぐ・弧・ギザギザ・くの字 |
| 8 の字 | 真ん中の軸のまわりの輪が、ハサミのように閉じて輪の中をつぶす（全体がゆっくり回る） | 輪の数 2〜5 個、刃の形 弧・まっすぐ |
| はさみ箱 | 左右から「[」と「]」が入ってきて箱になり、横から挟んでつぶす | — |

ふだんは「おまかせ」で、毎回ちがう仕掛け・刃になります。

## 操作

マウスを動かす（スマホは画面をさわる）と、下に操作の帯が出ます。しばらくさわらなければ、帯もマウスの矢印も消えます。

| ボタン | キー | すること |
|---|---|---|
| ⏸ ／ ▶ | スペース | 止める・動かす |
| ⏭ | N（または →） | 次の回へ |
| 仕掛けの欄 | 1〜3 ／ 0 | 仕掛けを選ぶ（1 寄せ刃・2 8 の字・3 はさみ箱）／ 0 でおまかせ |
| 🔊 | M | 音を消す・出す |
| 音量のつまみ | ↑ ↓ | 音量 |
| ⚙ | | 設定（下の表） |
| ⛶ | F（または画面をダブルクリック） | 全画面 |

### 設定（⚙）

| 見出し | 項目 | 中身 |
|---|---|---|
| 基本 | 玉の大きさ | おまかせ／大／中／小／極小 |
| | 分かれる数 | おまかせ／2 つ／3 つ／4 つ |
| | 速さ | ふつう／ゆっくり／はやい／とてもはやい |
| 増え方 | どこまで増やす | おまかせ（円の 3 倍）／円の 2 倍／円の 5 倍／1 万個／3 万個／10 万個 |
| | 生まれた玉を守る | 次の 1 回／次の 2 回／守らない（守らないと、刃の間に残った玉がどんどん増えます） |
| | 生まれた玉をはじき出す | ふつう／強く／しない |
| 減るもの | 減らすもの | おまかせ／なし／食べる玉／穴／寿命／消し刃 |
| | 強さ | ふつう／弱い／強い |
| 寄せ刃 | 刃の数 | おまかせ／2 枚（プレス）／3 枚／4 枚（十字）／5 枚／6 枚／8 枚 |
| | 刃の形 | おまかせ／まっすぐ／弧／ギザギザ／くの字 |
| 8 の字 | 輪の数 | おまかせ／2〜5 つ |
| | 刃の形 | おまかせ／弧／まっすぐ |
| 計算 | 細かさ | ふつう／軽く（玉がとても多いとき）／なめらか |
| 表示と音 | 音量・玉の数を出す | 音量は画面のせまいとき（スマホなど）ここに出ます。玉の数は C キーでも切りかえ |

「速さ」「守る」「はじき出す」「細かさ」は、変えるとその場から効きます。ほかは変えるとすぐ次の回になります。
設定はこの PC のブラウザが覚えています（次に開いたときも同じ）。

## 困ったとき

- **音が出ない** … 画面を 1 回クリックしてください（ブラウザは、さわるまで音を出さないきまりです）。🔊 が消音になっていないかも見てください。
- **動きがかくかくする** … 玉が多すぎます。設定の「どこまで増やす」を小さく、「細かさ」を「軽く」に、「玉の大きさ」を「大」か「中」にしてください。
  重いときは、細かさを自動で少し下げます。
- **窓の大きさを最初にもどしたい** … ふえる玉を閉じてから、`data` フォルダを消してください（専用の窓の設定がここに入っています）。
